# legacy/ —— 旧入口归档

这里的文件是项目演进过程中的旧版本，**已不再维护**，保留只为留档与答辩时说明“做过哪些迭代”。
当前唯一演示入口是项目根目录的 `app.py`（或双击 `启动吃饱饱.bat`）。

| 文件 | 说明 | 为什么被替换 |
|---|---|---|
| `app_streamlit.py` | Streamlit 图形界面 | 依赖 streamlit；启动慢、样式不可控 → 换成原生 `ui/` + `server.py` |
| `webchat.py` + `web/` | 第一版网页版对话 | 逻辑散在单文件、没有四条推荐/餐别层 → 拆分到 `server.py` + `ui/` |
| `agent_chat.py` | 终端智能体对话 | 答辩时终端不好看 → 换桌面窗口，工具调用过程改为界面卡片 |
| `cli.py` | 菜单式脚本（不含 LLM） | 纯工具演示，已被转盘/推荐覆盖 |
| `wheel.html` | 独立动画版转盘 | 单文件演示，与智能体脱节 |
| `slides.html` | 期末汇报幻灯片 | 只作文档留档，演示用真实应用 |
| `1-自动演示.bat` / `2-自己对话.bat` / `3-网页版对话.bat` | 旧启动器 | 入口已收敛为 `启动吃饱饱.bat` |
