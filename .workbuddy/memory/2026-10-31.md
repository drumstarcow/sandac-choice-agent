## 第七次改动（同日）：新增双击启动器（用户说"我咋跑啊，不理解"）

用户不懂命令行，需要零门槛运行方式。

### 关键踩坑（可复用，重要）
**`.bat` 里不能直接写 UTF-8 中文**：cmd 按系统代码页（GBK）读取 bat 文件，
UTF-8 中文会变乱码字节，并且会把命令行**截断**——`echo 中文` 被解析成
「'乱码' 不是内部或外部命令」，后面的行也连带错乱。
首行 `chcp 65001` 也救不了（文件已被按 936 读过一轮，混合编码会断行）。
→ 解法：**bat 里只写 ASCII**，所有中文提示交给 Python 打印（`banner.py`），
  配合 `chcp 65001` + `set PYTHONUTF8=1` + `set PYTHONIOENCODING=utf-8`。
→ 实测：这样跑出来 117 行输出**零乱码**，emoji（🔧🎡📇🏆）全部正常显示。

另一个坑：`set PYTHONUTF8=1` 若行末带空格，值变成 `"1 "`，
Python 直接 `Fatal Python error: preconfig_init_utf8_mode: invalid value`。
本机写 bat 时务必确认行末无尾随空格（或改用 `set "VAR=值"` 形式）。

## 第八次改动（同日）：修复双击启动器报 "Python not found in PATH"

### 关键坑（非常重要，以后写 bat 必看）
**「命令行能跑 python」≠「双击 bat 能跑 python」**。
- 双击 bat 继承的是**用户级系统 PATH**，本机其中 `python` 命中
  `C:\Users\13601\AppData\Local\Microsoft\WindowsApps\python.exe`
  —— 这是**微软商店占位符**，执行会跳转商店 / 直接失败。
- 而开发调试时的 shell 的 PATH 被注入了可用解释器
  （`.workbuddy\binaries\python\...`），所以我在 bash 里测 `python -V` 一直成功，
  **完全掩盖了这个问题**。
- 本机真实可用的是 `py -3`（Python 3.14，装在
  `%LOCALAPPDATA%\Programs\Python\Python314`），但没勾 Add to PATH。

### 修复
启动器里加解释器探测，按优先级：
1. `py -3 -c "import sys"` 能否成功
2. 绝对路径 `%LOCALAPPDATA%\Programs\Python\Python314/313/312\python.exe`
3. `%USERPROFILE%\.workbuddy\binaries\python\envs\default\Scripts\python.exe`
4. `%USERPROFILE%\.workbuddy\binaries\python\versions\3.13.12\python.exe`
找到后存进 `%PYEXE%`，并打印在 `[2/2] ...(interpreter: ...)` 行，便于排错。

### 验证方法（重要，可复用）
**不能直接用当前 shell 测 bat**，因为 PATH 被污染。必须模拟真实双击：

（把 bat 先复制成 ASCII 文件名，避免命令行传中文路径的编码坑）
结果：两个启动器都成功探测到 Python314，146 行完整跑通，
`recommend_nearby_food` → `build_wheel` → `finalize_decision` 全部真实调用并落盘。

另外：模型热加载后整段 demo 只要 **4 秒**（冷启动才 2 分钟），别把"跑太快"误判成出错。

### 踩到的坑（都很值得记）
1. **前端只报 `Failed to fetch` 时，多半是后端 500 或异常直接把连接掐了**。
   真因：`history.summarize_recent_profile` 里 `float(h["budget"])`，而我在 finalize 时
   把 `SESS.budget`（值为 `"不限"`）写进了历史 → ValueError → `/api/state` 崩 →
   `do_GET` 没有 try/except → 连接断开 → 浏览器只看到 Failed to fetch。
   → 修：history 加 `_num()` 安全转换；`do_GET` 也包 try/except 返回 500 JSON。
2. **0.5B 会把工具参数填成自然语言**：`build_wheel({"scene":"附近吃去哪"})`，
   严格枚举匹配 → 转盘为空 → 界面上什么都不出来。
   → 修：`tools._normalize_scene()` 按关键词归一化，兜底回 `where`。
3. **Canvas 径向文字在左半圈会倒读**：mid 角落在 (90°,270°) 时要 `rotate(mid+π)`
   并把 `textAlign` 从 right 翻成 left、绘制点取负号。
4. 转盘卡片做大了会顶到输入区 → 需要 `scrollDown` 在 `rAF/80ms/420ms/900ms` 多次触发，
   单次 rAF 在卡片入场动画（380ms）期间算的 scrollHeight 是旧值。
5. 按钮里的 ✅/❌/🔁 在部分环境渲染成方块 → 改用 `✓`/`✕` 纯文本符号。
