## P0-1 模型可切换（默认云）

**现状**：`agent.py:29-31` 写死成本地 Ollama 小模型
```python
BASE_URL = os.getenv("OLLAMA_BASE_URL", "http://localhost:11434/v1")
MODEL = os.getenv("OLLAMA_MODEL", "buding-qwen05b-32k:latest")
API_KEY = os.getenv("OPENAI_API_KEY", "ollama")
```

**要改成**：
```python
PROVIDER = os.getenv("MODEL_PROVIDER", "cloud")
if PROVIDER == "cloud":
    BASE_URL = os.getenv("CLOUD_BASE_URL", "https://api.deepseek.com/v1")
    MODEL    = os.getenv("CLOUD_MODEL", "deepseek-chat")
    API_KEY  = os.getenv("CLOUD_API_KEY", "")
else:
    BASE_URL = os.getenv("LOCAL_BASE_URL", "http://localhost:11434/v1")
    MODEL    = os.getenv("LOCAL_MODEL", "qwen2.5:7b-instruct")
    API_KEY  = "ollama"
```

**新建 `.env`**（当前目录只有 `.env.example`）：
```
MODEL_PROVIDER=cloud
CLOUD_BASE_URL=https://api.deepseek.com/v1
CLOUD_API_KEY=填你的key
CLOUD_MODEL=deepseek-chat
LOCAL_BASE_URL=http://localhost:11434/v1
LOCAL_MODEL=qwen2.5:7b-instruct
```

**启动必须打印一行**：`模型：deepseek-chat（云）`
**失败兜底**：cloud 且 key 为空 → 打印红字「未配置 CLOUD_API_KEY，已回退本地」，并自动切 local，不要直接崩。

**验收**：`python preflight.py` 输出 `模型 OK：deepseek-chat（云）`

## P0-5 preflight.py

依次检查并输出：
1. `模型 OK` — 云：用 1 token 探活；本地：`GET /api/tags` 且在列表里
2. `数据 OK` — 菜品/店铺 JSON 存在且条数 > 0，打印条数
3. `工具 OK` — 直接调 `tools.build_wheel('where')` 与一次 reroll，能返回合法 JSON
任一失败：红字 + 退出码 1。

## P1-1 第 0 层：餐别

选项 `正餐 / 甜品饮料 / 随便`。选「随便」→ 立即 roll（各 50%），并把结果写进上下文：`meal_type=dessert`。
后续菜品池按 `meal_type` 过滤（正餐：主食/菜/面饭；甜品：饮品/甜品/冰品）。

## P1-2 三层保持

场景（食堂/外面吃/外卖）→ 口味（辣/不辣/随便，选随便=该层不参与过滤）→ 菜品格子。

## P1-3 菜品格子

- 网格布局，每格显示缩略信息（名称 + 价格）
- 动画：从一格跳到下一格，节奏 80~120ms，减速停下（约 25~35 次跳动）
- 停下的格子放大为卡片：图 4:3、名称、40~50 字描述、距离/价格/评分
- 数据字段至少：`id name img desc price distance rating tags meal_type`

## P1-4 四条并列推荐

同一收尾函数 `finalize(...)` 输出四条：
| 类别 | 排序键 |
|---|---|
| 综合最佳 | `score = 0.5*norm(评分) + 0.3*norm(1/价格) + 0.2*norm(1/距离)` |
| 最近 | distance 升序 |
| 最便宜 | price 升序 |
| 评分最高 | rating 降序 |
每条前面加一句理由，例如「走 3 分钟就到，评分 4.6」。
**注意去重**：同一家店同一道菜不要重复出现在两条里，重复就顺延下一位。
