# 🍱 吃饱饱助手 · 帮我决定今天吃啥（校园决策智能体）

> **开源创新微专业 · 期末考查（路径 B：校园服务智能体）**
> 自然语言理解 → 真实 Tool Calling → 四层决策转盘 / 四条并列推荐 → 记忆画像 → 打卡卡片落盘。

## 一、项目简介

大学生“选择困难”是真实痛点：站在食堂门口不知道吃啥、想吃辣又怕踩雷、想出去吃又不知道附近哪家值。
本项目把「帮大学生做选择」做成智能体的核心能力，三条路都走得通：

**① 四层决策转盘**（没想法时用）
- 第 0 层 **餐别**：正餐 / 甜品饮料（「都行，你替我定」在盘外，点了各 50% 立刻 roll）
- 第 1 层 **场景**：食堂 / 外面吃（「外卖」不单列：周边店铺堂食外卖同一批，多一个扇区等于假选项）
- 第 2 层 **口味**：辣 / 不辣（「都行」同上，点了该层不过滤）
- 第 3 层 **菜品**：菜品格子跳动落点（约 28 次跳动，80→210ms 减速），停下的格子放大成名片
- 任一层的选项都可以**拒绝**：该选项权重清零、永久剔出本会话，其余按权重归一化重排，**概率数字就在扇区上**；拒到只剩一个时会直接告诉你「没得转了，直接定」
- **「随便」为什么不在扇区里**：它跟真实选项混在一张盘上时，一旦你拒掉其中一个，剩下的「随便」≡ 另一个选项，转盘就没有悬念了 —— 所以它被做成盘外的独立按钮，扇区只放互斥的真选项

**② 四条并列推荐**（有想法、要方案时用）
同一收尾函数 `tools.finalize()` 一次输出四条，跨条自动去重（同店同菜重复就顺延下一位）：

| 类别 | 排序键 |
|---|---|
| 综合最佳 | `0.5*norm(评分) + 0.3*norm(1/价格) + 0.2*norm(1/距离)` |
| 最近 | distance 升序 |
| 最便宜 | price 升序 |
| 评分最高 | rating 降序 |

每条前面都带一句人话理由，例如「走 3 分钟就到，评分 4.6，饿的时候别犹豫」。

**③ 点名直达**：用户说「想吃火锅」时不经转盘，模型自己判断并调 `search_dish(keyword="火锅")`，直接出四条。

匹配分三档，**绝不把整个候选池冒充成「最接近的方案」**：
1. 菜名/店名命中（如「黄焖鸡米饭」「海底捞」）→ 直接给命中项
2. 沾边但没这道菜（如「海南鸡米饭」）→ 明说「菜单里没有，最接近的是」并给相近项
3. 完全没有（如「佛跳墙」）→ 按同类线索替代（面/鸡/汤…），连线索都没有就说「这几样是今天评分靠前的」

**记忆能力**
- 用户画像（`data/profile.json`）：校区（定位圆心）/ 预算上限 / 口味偏好 / 忌口 / 饮食限制
- 选择历史（`data/history.json`）：每次收尾都留痕，最近 10 条聚合成「近期画像」，界面右上角偏好面板可见可删

**收尾产出**
点「就它了」生成固定尺寸打卡卡片：菜名 / 店名 / 价格 / 距离 / 评分 / 一句打卡文案 / 日期，附「复制文案」与「截图提示」，同时落盘 `outputs/今日决定_*.md`。

## 三、技术栈

- **语言**：Python 3.10+（3.14 实测），**零第三方依赖**：`urllib` 调模型、`http.server` 起服务、Canvas 画转盘

## 五、环境要求与运行

### 0. 最快方式（不用命令行）

双击 **`启动吃饱饱.bat`** → 自动探测 Python → 起服务 → 弹出应用窗口。
关掉那个黑窗口就停止服务（已生成的卡片在 `outputs/`，不会丢）。

### 1. 命令行方式

```bash
python preflight.py     # 自检：模型 / 数据 / 工具
python app.py           # 启动（默认自动找空闲端口，从 8770 起）
python app.py 8780      # 指定端口
python app.py --no-win  # 只起服务，浏览器自己开
```

### 2. 模型配置（`.env`）

```ini
MODEL_PROVIDER=cloud                       # cloud 优先；改 local 则只用本地
CLOUD_BASE_URL=https://api.deepseek.com/v1
CLOUD_MODEL=deepseek-chat
CLOUD_API_KEY=                             # 填你的 key；留空会自动回退本地
LOCAL_BASE_URL=http://localhost:11434/v1
LOCAL_MODEL=qwen2.5:7b-instruct            # 本机没这个型号会自动换成已装的 qwen
```

- 启动必定打印一行：`模型：deepseek-chat（云）`
- `cloud` 且 key 为空 → 红字 `⚠ 未配置 CLOUD_API_KEY，已回退本地模型`，不崩
- 云端请求失败（断网 / 401 / 欠费）→ 自动切本地，界面蓝标提示「网络不可用 → 已切本地模型」，其余功能照常

### 3. 本地模型（只在回退时用）

```bash
ollama pull qwen2.5:7b-instruct   # 或用本机已有的 qwen 系
ollama serve
```

## 六、演示话术（上台参考）

1. **开场**：「它只干一件事 —— 帮你决定今天吃什么。」
2. **没想法**：输入「随便」→ 转盘起盘，点击「转一下」→ 指出扇区上的百分比是真实权重
3. **拒绝**：转到不满意的，点「换一个（拒绝）」→ 该扇区红灰划掉、其余概率变大，**说明权重清零 + 归一化**
4. **落点**：菜品层是格子跳动，停下放大成名片（图 4:3 / 描述 / 距离 / 价格 / 评分）
5. **四条**：「同一份数据，四个维度各挑一条，还自动去重」
6. **收尾**：「一句打卡文案是模型现写的」→ 点「就它了」→ 复制文案
7. **点名直达**：新开一轮，输入「想吃火锅」→ 模型自己调 `search_dish`，不转盘
8. **一键演示**：右上角按钮，8 步跑完全场。演示**不是直接跳结果**——每一层都在真实画布上把转盘转完、格子跳完再推进，拒绝后能看到概率真的重排；演示途中按钮会变成「■ 停止演示」可随时中止

> 三句最值钱的话：
> ①「概率不是动画，是后端 `WheelEngine` 算的，拒绝后真的重排。」
> ②「这四个方案不是四段 if-else，是同一个 `finalize()` 按四个排序键各取一条。」
> ③「模型调用失败会自动降级到本地模型，所以断网也能演示。」

## 八、转盘概率模型与验收清单

### 8.1 权重概率模型（真实代码，非提示词 if-else）

```python
DECAY = 0.6
抽中后：w *= 0.6        # 避免连着抽同一个
被拒绝：w  = 0.0        # 本会话永久剔除
每次抽取：p_i = w_i / Σw  # 归一化，扇区上直接显示
```

### 8.2 Tool Calling 契约

- 模型返回的 `tool_calls` 是**结构化读取**的，界面按 `calls[]` 渲染，**不解析 emoji、不解析任何文本标记**
- 全仓 `grep` 扳手 emoji（U+1F527）应为 **0 条**（历史版本曾用这个字符判断"模型有没有调工具"，已彻底移除）
- 日志按来源打标，评审可据此判断哪次是模型真调用：

  | 日志 | 含义 |
  |---|---|
  | `[TOOL] source=model ...` | 模型自己决定调用的工具（答辩重点看这个） |
  | `[TOOL] source=orchestrator ...` | 界面操作触发（点某层转盘、确认、收尾） |
  | `[TOOL] source=fallback ...` | 模型异常后的兜底执行，仍真实调用工具 |

- 兜底只在**两种**情况触发，且必定同时写 `SESS.used_fallback`、打 `[FALLBACK] reason=...`、界面黄标签「兜底模式」：
  1. `agent.chat()` 抛异常或返回 `status=error`（`try/except` 分支）
  2. 模型这一轮 `tool_calls=0 且 content 为空`（完全空返回，`reason` 会带上 `status=... tool_calls=0 content=0`）
- 正常演示全程不应出现 `[FALLBACK]`；出现即为异常，需要看 `reason`

### 8.3 挑刺测试清单（交前逐条跑）

| # | 操作 | 期望 |
|---|---|---|
| 1 | `python preflight.py` | 三行 OK，退出码 0 |

## 九、故障排查

**打开是 404「错误响应 / 文件未找到」** —— 上次的窗口没关干净，旧进程还占着 8770。
旧版本用 `SO_REUSEADDR`，Windows 上会允许两个进程绑同一端口（先监听的收包），于是新服务看着起来了、浏览器连的还是旧服务。
现已改为**独占绑定 + 起服务后自检「返回的是不是我自己的页面」**，遇到占用会自动换 8771 并在控制台提示：

```
⚠  端口 8770 已被其它程序占用（多半是上次没关干净的窗口），改用 8771
```

想彻底清干净，把残留的 Python 窗口都关掉（或按地址里提示的端口访问）。
