# DESIGN.md — 吃饱饱助手 · 期末答辩

## 全局视觉约定

### ① 画布与安全区

- 画布 1280×720
- padding：上下 60 / 左右 60，内容区 1160×600
- 页尾顶边固定 y=670（左：吃饱饱助手 · 校园吃饭决策智能体；右：NN / 12），封面与结尾页不加页尾

### ② 配色（沿用产品自身配色）

| 槽位 | Hex | 用途 |
| --- | --- | --- |
| 主色 | `#E8622C` | 标题重音、编号块、流程节点、表头 |
| 辅色 | `#F4E3D3` | 浅底卡片、表格斑马行 |
| 深色 | `#2B1D14` | 深色强调卡（每页 ≤1 块）、正文重字 |
| 底色 | `#FDF7EF` | 页面背景 |
| 正文色 | `#3A2E24` | 主文字 |
| 弱化 | `#8A7A6B` | 脚注、次级说明 |
| 线 | `#E2D3C2` | 1px 分隔线 |

### ③ 字体

- 中文：微软雅黑；西文：Arial
- 阶梯：封面主标 84 / 超大数字 96 / 章节大字 56 / 页面主标 36 / 卡片小标 24 / 正文 18 或 20 / 脚注 14

### ④ 视觉母题

- 每页顶部：`NN · 页名`（14px，主色，字距 2）→ 主标题 36px → 一条贯通内容区的 1px 细线（`#E2D3C2`），标题顶边固定 y=60
- 卡片一律圆角 8px，无阴影，层次靠底色与 1px 线

## anti_pattern 逐页

- P1：禁止封面出现数据指标（174/111/63 不上封面）；禁止居中大字报堆三行副标
- P2：禁止把对话做成等宽两栏；禁止聊天记录用图片代替（必须可编辑文字）
- P3：禁止裸露表格（外层必须有容器）；禁止三列等宽
- P4：禁止五段用等宽卡片横排代替流程链；禁止节点内塞多行段落
- P5：禁止两张截图等大并排无主次；禁止截图变形拉伸
- P6：禁止代码块占满整页；禁止三条说明用等大卡片
- P7：禁止左图右文各占 50%
- P8：禁止六层做成等宽等高的六个方块网格
- P9：禁止表格四列等宽；禁止在表格里塞整段话
- P10：禁止三栏等宽
- P11：禁止「问题 / 方案」两列等宽对切
- P12：禁止只写「谢谢」占整页
